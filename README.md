# Prospectum Skills Lab

Public working repository for reusable AI, sales intelligence, and B2B revenue operations skills developed around Prospectum and IA-90.

## Purpose

This repository is intended to become a curated library of reusable workflows for:

- B2B prospecting and account enrichment.
- ICP scoring and segmentation.
- HubSpot-ready data preparation.
- Chilean company enrichment with public sources.
- Outreach QA and pre-send validation.
- AI-assisted revenue operations.

## Operating principle

Useful work becomes a skill only when it is:

1. Repeatable.
2. Executable.
3. Verifiable.
4. Safe to reuse.
5. Relevant to revenue, productivity, or operational risk.
